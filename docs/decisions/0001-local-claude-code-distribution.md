# Local Claude Code distribution

Status: accepted for v0.1.

Install generic skills per checkout from a trusted local Nexus source. Keep
conventions, reports, and manifests in OS user data. Use a canonical path to
identify a checkout. This provides explicit project scope and avoids dependency
on a package registry or runtime service for installation. Moved checkouts and
separate worktrees need their own project configuration. Revisit shared identity
after gathering evidence from the pilot.
