# Foundation plan

The product provides portable skills, repeatable installation, and approved
project conventions. It starts with software development in Claude Code.

| Stage | Acceptance |
| --- | --- |
| Foundation | Locked environment, portable CLI, contribution and security guides, CI and secret scanning |
| Pilot | Install bootstrap, planning, and review in a disposable Git project, invoke all three in Claude Code, and confirm private conventions persist |
| Lifecycle | Verify idempotence, conflicts, interruption recovery, rollback and preservation of unrelated files |
| P0 | Add Git branch, commit, pull request, and grilling workflows with explicit invocation |
| Close | Execute the platform CI matrix and confirm the Claude Code pilot before declaring support |

The CLI and P0 skill definitions are in the repository. The Windows pilot
verified installation, convention readback, and discovery of the three pilot
skills in Claude Code 2.1.332. Authenticated skill invocation and hosted CI
remain pending. Verify runtime version support and package name availability
before publishing.

Future stages cover contextual retrieval and handoffs, orchestrated agents,
distributed work, externally enforced corporate isolation, an executive
assistant, evaluation-driven optimization, and new workflow domains.
