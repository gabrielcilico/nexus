# pull-request

Identify the provider, head, base, template, and supplied ticket. With an authorized domain, query `nexus config get base_branch pr_language --domain <domain>`. Summarize implementation, test evidence, and residual risks in the template. Present a local draft by default. Before publishing or pushing, confirm authorization for the operation and destination. Treat merge and deploy as separate workflows.
