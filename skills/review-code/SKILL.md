# review-code

Establish the diff and acceptance criteria. With an authorized domain, query only relevant fields such as `nexus config get base_branch test_command --domain <domain>`. Trace affected callers and verify concrete failures when possible. Report findings by severity with file, line, triggering conditions, and impact. Record any checks run and any material verification gaps.
